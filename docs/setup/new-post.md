# 새 글 추가 절차

## 필수 단계

새 글을 추가할 때는 다음을 모두 수행합니다.

1. 해당 카테고리 폴더에 `<category>/NN-*.md` 본문 파일 생성
2. 짝이 되는 `<category>/examples/NN-*/` 폴더 생성 (예제 코드가 있는 경우). 본문에서는 `./examples/{폴더명}/index.js`로 링크합니다.
3. `README.md` 목차 테이블에 행 추가

번호(`NN`)는 같은 카테고리 내에서 순서를 관리하는 용도입니다.

## 참고할 기존 글

카테고리별로 레퍼런스 구현이 다를 수 있으므로, 해당 카테고리 내에서 이미 완성된 글을 기준으로 삼습니다.

- `javascript-core`: `01-javascript-engine-and-runtime.md`, `02-execution-context.md`가 구조·서식·깊이의 레퍼런스입니다.

새 카테고리를 시작할 때는 첫 1~2편을 그 카테고리의 레퍼런스로 정하고, 이후 글은 그 스타일에 맞춥니다.
