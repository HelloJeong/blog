이 카테고리의 `.md` 글을 **작성·편집·리뷰**할 때 쓰는 요약 체크리스트입니다. 상세 규칙은 [`docs/feature/javascript-core-writing.md`](../docs/feature/javascript-core-writing.md)에 있습니다.

## 헤더

- `# 번호. 제목` (예: `# 01. JavaScript 엔진과 런타임 환경`)
- 이탤릭 시리즈 인용구 + `./examples/{폴더명}/index.js` 참고코드 링크 + `---`

## 언어·톤

- 본문 한국어 **존댓말** (~합니다)
- 코드 주석은 **반말** (`// 값을 반환한다`)
- 영문 용어는 원어 + 첫 등장 시 한국어 병기 (`AST(Abstract Syntax Tree)`)
- 번역하면 어색한 표현은 영문 풀네임 그대로 (`silent failure` 등). 자연스러운 한국어 대응어가 있으면 한국어 우선
- **단정적 부정 표현 회피**: 의도에 따라 정상일 수 있는 동작을 "버그"·"문제"로 단정 짓지 말고 "사실 → 함정이 되는 조건" 순서로 풀기

## 섹션 구성

- 각 `##` 섹션: 개념 정의 → 시각자료(표/다이어그램/코드 중 1개 이상) → 상세 설명 → `---`
- 제목은 질문형/흐름형/비교형/주장형 중 자연스러운 형태 선택
- 단계별 흐름은 먼저 다이어그램, 그다음 번호 매긴 설명

## 코드·시각자료

- 코드 블록은 언어 태그 필수(` ```javascript `), 30줄 이내
- ❌/✅ 이모지로 나쁜/좋은 예시 대비
- 실행 결과는 `// 출력: ...` 주석으로 표기
- 구조/흐름은 텍스트 다이어그램(`↓`, `└──`), 비교는 마크다운 테이블

## 강조·인용

- 핵심 용어는 **굵게**, 코드/API명은 `` `인라인` ``
- `>` 인용구는 팁·참고·면접 질문에 사용

## 마무리

- 마지막 섹션은 `## 정리` — 3~5개 불릿, **굵은 키워드** 포함, 서술체(~한다)
- 정리 아래 게시글 모음 링크 추가
- 본문 분량 150~400줄
