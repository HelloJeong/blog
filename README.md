## 시리즈 소개

### 대상 독자

- JavaScript를 실무에서 사용하고 있지만, 핵심 원리를 깊이 있게 정리하고 싶은 개발자
- React, NestJS 등 프레임워크 위주로 개발해오면서, "왜 이렇게 동작하지?"라는 질문에 명확히 답하고 싶은 개발자

### 각 글의 구성

1. **핵심 개념** — 해당 주제의 정의와 왜 알아야 하는지
2. **동작 원리** — 내부적으로 어떻게 작동하는지 (엔진 레벨)
3. **코드 예제** — 실무에서 볼 수 있는 패턴 중심
4. **흔한 실수** — 면접/실무에서 자주 틀리는 포인트
5. **실무 연결** — React, NestJS 등에서 이 개념이 어떻게 쓰이는지
